# Komentář k zákonu České národní rady č. 565/1990 Sb., o místních poplatcích

Otevřený komentář k zákonu o místních poplatcích (MPopl) — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; poplatek ze psů, z pobytu, za užívání veřejného prostranství, ze vstupného, za vjezd, za zhodnocení pozemku, poplatky za komunální odpad, zavedení obecně závaznou vyhláškou a správa poplatků podle daňového řádu.

Konsolidované znění: dokument e-Sbírky `SB-1990-00565_2025-01-01`.
